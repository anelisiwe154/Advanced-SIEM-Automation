# Project Roadmap

This roadmap outlines planned features and enhancements for the project. Contributors are encouraged to pick items from this roadmap and open issues/PRs.

## Short-Term Goals (2026)
-  Fix Rule validation bug (#45)
-  Improve User deactivation error handling (#46)
-  Add Redis caching for faster alert lookups
-  Implement role-based access control (RBAC)

## Medium-Term Goals (2026)
-  Integrate with external threat intelligence feeds
-  Add dashboard visualization (Grafana/Streamlit)
-  Support Docker deployment

## Long-Term Goals (2027)
-  Machine learning module for anomaly detection
-  Integration with cloud SIEM platforms (Azure Sentinel, Splunk)
